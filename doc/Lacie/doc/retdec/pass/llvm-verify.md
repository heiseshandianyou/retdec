# LLVM Standard Pass: verify

`verify` 是 LLVM 中最基础的静态检查 Pass，用于验证 LLVM IR 模块在逻辑上和结构上的正确性。

## 核心功能

1.  **结构验证**：确保 IR 遵循 LLVM 的语法规范。例如，基本块必须以终止指令（如 `ret`, `br`）结尾。
2.  **类型安全检查**：检查指令的操作数类型是否匹配。例如，`add` 指令的两个操作数必须是相同的整数类型。
3.  **SSA 规范检查**：验证静态单赋值（SSA）形式的完备性。例如，每个变量在使用前必须已被定义，且定义必须支配（Dominate）其所有使用点。
4.  **内建函数约束**：检查对 LLVM Intrinsic 函数（如 `llvm.memcpy`）的调用是否符合其参数和属性要求。

## 算法原理

`verify` 采用深度遍历的方式扫描模块：
- **Module 级别**：检查全局变量声明、函数定义和元数据的一致性。
- **Function 级别**：
    -   验证控制流图（CFG）的连通性。
    -   使用支配树（Dominator Tree）检查变量的作用域规则。
- **Instruction 级别**：针对每种特定指令执行其专属的校验算法。

## 在 RetDec 中的作用
RetDec 在运行自定义优化 Pass 之间频繁调用 `verify`，以确保反编译生成的 IR 或经过变换后的 IR 仍然符合标准，避免因编译器错误导致后续转换崩溃。
