# LLVM Standard Pass: gvn (Global Value Numbering)

`gvn` 是一种强大的全局公共子表达式消除和多余指令消除技术。

## 核心功能

1.  **全局子表达式消除**：跨越基本块寻找逻辑上产生相同结果的复杂指令序列，并将其合并。
2.  **加载消除（Load Elimination）**：
    -   识别在一个加载指令被执行前，内存是否已经被赋予了确定的值。
    -   通过分析别名信息和控制流，消除跨基本块的重复内存读取。
3.  **推导式常量折叠**：利用由于条件跳转隐含的约束信息来推断常量值（例如在 `if (x == 5)` 块内，将 `x` 视为 5）。

## 算法原理

- **值编号（Value Numbering）**：为每个产生值的指令分配一个整数编号。如果两条指令的操作符相同且其操作数的编号也相同，则它们被赋予相同的值编号，意味着它们是等价的。
- **支配性分析**：利用支配树来决定哪一个等价结果应该被保留，并作为其他地方的引用来源。

## 在 RetDec 中的作用
`gvn` 相对于 `early-cse` 提供了更深层的数据流理解。它能有效地识别并简化二进制程序中复杂的由于地址计算和间接引用导致的冗余逻辑。
