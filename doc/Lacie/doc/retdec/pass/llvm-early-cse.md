# LLVM Standard Pass: early-cse (Early Common Subexpression Elimination)

`early-cse` 提供了一种轻量级、快速的公共子表达式消除（CSE）和冗余加载消除算法。

## 核心功能

1.  **公共表达式消除**：如果在一个支配路径上已经计算过完全相同的表达式（相同操作符及操作数），则复用之前的结果。
2.  **死指令移除**：顺带移除那些结果从未被使用且没有副作用的指令。
3.  **冗余加载消除**：如果在同一变量刚被存储后立即加载，则直接使用被存储的值。

## 算法原理

- **单遍遍历**：该 Pass 仅对函数进行一次深度优先遍历。
- **哈希匹配**：使用哈希表（ScopedHashTable）存储已遇到的指令。由于它在优化流程的早期运行且不维护复杂的依赖关系，因此速度极快。
- **简单支配规则**：它主要利用支配树来确保替换的安全性。

## 在 RetDec 中的作用
作为前端解码后的第一批优化 Pass 之一，`early-cse` 能够在大规模、高开销的分析（如 GVN）之前，快速清理掉一大半由于汇编指令展开导致的显而易见的代码重复。
