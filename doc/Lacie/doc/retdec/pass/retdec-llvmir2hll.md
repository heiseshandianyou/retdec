# LLVM Pass: retdec-llvmir2hll

`retdec-llvmir2hll` 是 RetDec 的后端核心，负责将经过深度优化的 LLVM IR 转换为人类可读的高级语言（HLL），如 C 语言。

## 核心功能

1.  **BIR 转换**：将 LLVM IR 转换为 RetDec 特有的 **BIR (Backend Intermediate Representation)**。BIR 是一种抽象语法树（AST）级别的表示，比线性 LLVM IR 更适合进行结构化分析（如还原 if-else, loops）。
2.  **结构化恢复**：通过控制流图（CFG）分析，将跳转指令转换回高级控制结构（循环、分支、条件）。
3.  **变量语义增强**：
    -   **变量重命名**：为反编译出的变量生成更具意义的名称。
    -   **类型清理**：修复 LLVM IR 中模糊的符号位信息（Signed vs Unsigned）。
4.  **后端优化**：执行一系列针对 HLL 生成的优化，如死代码删除、表达式化简、变量归并等。
5.  **代码发射（Emission）**：通过 HLL 写入器（HLLWriter）生成最终的 C 源代码文件。

## 主要阶段

该 Pass 内部包含多个子阶段，依次执行：

### 1. 初始化与转换
- **初始化**：加载配置，设置别名分析、变量重命名器、语义库等。
- **LLVM-to-BIR 转换**：将 LLVM 的指令序列映射为 BIR 指令和表达式。

### 2. 预处理与清理
- **移除库函数**：隐藏来自标准库（如 libc）的函数体，仅保留原型。
- **不可达代码移除**：删除 CFG 中无法到达的代码块。
- **Intrinsic 转换**：将 LLVM 特有的内置函数（如 `llvm.memcpy`）转换为标准库调用。

### 3. 后端分析与优化
- **别名分析**：建立变量间的别名关系，为变量优化提供依据。
- **变量优化**：
    - 合并逻辑上重复的变量。
    - 提升局部变量的可见性。
- **表达式简化**：利用代数运算法则简化复杂的反编译表达式。

### 4. 符号化与命名
- **常量符号化**：将魔数（Magic Numbers）替换为对应的符号常量（如枚举值、宏定义）。
- **重命名**：根据配置规则（如基于使用频率或调试信息）重命名变量和函数。

### 5. 代码输出
- **CFG/CG 发射**：如果用户要求，可以生成控制流图和调用图的 DOT 文件。
- **发射目标代码**：调用 `CHLLWriter` 将 BIR 树解析并格式化为最终的 C 代码。

## 总结
`retdec-llvmir2hll` 是反编译流程的终点，也是决定输出代码质量的最关键环节。它通过一套复杂的转换、优化和分析体系，成功地将机器级别的逻辑升华为开发人员可以理解的高级语言结构。
