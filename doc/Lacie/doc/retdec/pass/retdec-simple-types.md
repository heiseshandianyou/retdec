# retdec-simple-types

`retdec-simple-types` 是 RetDec 中的一个核心类型推断 Pass，用于通过分析代码中的数据流和指令约束，重建并应用基本数据类型（如整数、浮点数、指针、数组和结构体等）。

## 功能概述

在二进制反编译的早期，数据通常表现为无类型的字节序列。`retdec-simple-types` 的目标是根据“你是如何使用这个数据的”来反推“这个数据是什么类型的”。例如，如果一个值被用作 `Load` 指令的基址，它很可能是一个指针；如果它参与了浮点加法，它就是一个浮点数。该 Pass 利用这种传播机制，在整个函数范围内构建出一套一致的类型体系。

## 算法流程

该 Pass 的算法是基于等价类（Equivalence Sets）和约束求解的复杂过程：

1.  **构建等价类（Building EqSets）**：
    -   遍历模块中的所有指令。
    -   如果两个值在指令中表现出“类型等价”或“类型关联”的关系（如赋值操作的两端、二元运算的两个操作数、函数调用与形参），则将它们归入同一个等价类（`EqSet`）。
    -   通过广度优先遍历（BFS）算法，不断扩展和合并这些等价类。

2.  **建立方程（Building Equations）**：
    -   为每个等价类建立关于其类型的方程。
    -   **优先级定义**（`eSourcePriority`）：根据类型来源的可信度设置优先级。例如，调试信息提供的类型 > 代码特征推断出的类型 > 默认类型。

3.  **类型传播（Propagation）**：
    -   **局部传播**：在每个等价类内部，根据定义的“优先级更高”规则（`getHigherPriorityType`）选出代表性类型。通常，更具体的类型（如结构体）优于抽象类型（如整数），带符号类型优于无符号类型。
    -   **迭代求解**：循环扫描等价类之间的关系（如指针解引用、数组访问），将类型信息在关联的集合间进行跨类传播，直到系统达到稳定状态。

4.  **应用类型（Applying Types）**：
    -   将最终推断出的类型应用到 LLVM IR 的变量和函数上。
    -   **强制转换处理**：如果推断出的类型与原始指令冲突，该 Pass 会利用 `IrModifier` 插入必要的 `bitcast` 指令，或者通过修改 `alloca` 指令的类型来强制同步。

## 核心规则：类型优先级（`getHigherPriorityType`）

在合并两种冲突类型时，算法有一套复杂的排序系统：
-   指针类型通常具有极高优先级。
-   在不同长度的整数之间，通常保留更宽的（或根据上下文确定的）。
-   结构体和数组类型比简单的标量类型具有更高的“结构化优先级”。

## 相关文件

-   `simple_types.cpp`: Pass 的主要控制器和等价类处理逻辑。
-   `simple_types.h`: 类定义。

## 总结

`retdec-simple-types` 是 RetDec 并发推断体系中的“推理引擎”。它通过捕捉指令之间的微小线索，利用复杂的数学等价模型，将底层的内存布局还原为高层的、具有语义一致性的类型系统，为生成易于阅读和编译的 C 代码提供了精细的数据描述。
