# LLVM Standard Pass: bdce (Bit-tracking Dead Code Elimination)

`bdce` 是一种精细的死代码消除技术，它不仅跟踪整个指令是否死亡，还跟踪指令产生的每一个 **位（Bit）** 是否被使用。

## 核心功能

1.  **无效位识别**：识别出某些计算结果中的位虽然生成了，但永远不会影响程序的最终输出。例如，一个 32 位加法的结果随后只被提取了低 8 位。
2.  **位级死指令删除**：如果一条指令的所有“有用位”都未被使用，则该指令可以被删除。

## 算法原理

- **已知位分析（KnownBits Analysis）**：利用 LLVM 内置的位追踪框架，计算每条指令输出的每个位是 0、1 还是未知的。
- **按需位分析（Demanded Bits）**：逆向分析使用点到底需要哪些位。

## 在 RetDec 中的作用
二进制程序中充满了位掩码和截断操作。`bdce` 能够帮助 RetDec 识别出那些为了对齐或清理而产生的冗余位计算逻辑，从而使生成的数学表达式更加精炼。
