# LLVM Standard Pass: sink (Code Sinking)

`sink` 负责将指令从当前位置移动到它的实际使用点所在的分支中。

## 核心功能

1.  **路径延迟执行**：如果一条指令计算的结果只在 `if` 语句的一个分支中被使用，`sink` 会将该计算指令从 `if` 之前移动到入该特定分支内部。
2.  **寄存器压力释放**：通过缩短变量的生存期，降低了对虚拟寄存器的占用。

## 算法原理

- **支配性校验**：必须确保下沉后的位置仍然支配所有的使用点。
- **副作用分析**：不能下沉具有外部副作用或在路径移动过程中可能发生语义变化的指令。

## 在 RetDec 中的作用
显著提升了代码的可读性。它能使复杂的计算逻辑紧贴着使用它们的分支，避免了在函数开头出现大量莫名其妙的中间计算结果，使得生成的 C 代码逻辑更加紧凑。
