# LLVM Standard Pass: instcombine (Instruction Combiner)

`instcombine` 是 LLVM 优化器中最核心、最庞大的 Pass。它通过模式匹配将多个简单的指令组合成更有效率的等价形式。

## 核心功能

1.  **代数简化**：应用算术运算法则（如 `x + 0 -> x`, `x * 1 -> x`）。
2.  **位运算压缩**：优化位移和掩码组合。例如，将连续的按位与操作合并。
3.  **常量折叠（局部）**：在指令层级直接计算已知常量的结果。
4.  **类型转换优化**：消除冗余的 `bitcast` 或类型提升（Zext/Sext）。
5.  **内存访问合并**：简化简单的 `getelementptr` 计算。

## 算法原理

- **工作队列机制**：`instcombine` 维护一个待处理指令队列。
- **单遍扫描 + 迭代**：它遍历函数中的每条指令，尝试匹配数千种预定义的“习语转换”。如果某条指令被修改，则可能触发其相关指令的进一步简化，这些指令会被重新加入队列。
- **贪心策略**：该 Pass 只执行能立即减小指令条数或降低复杂度的局部变换，不进行跨基本块的全局决策。

## 在 RetDec 中的作用
这是 RetDec 清理反编译产生的大量冗余指令的主要手段。通过反复调用 `instcombine`，可以将解码阶段产生的臃肿、低效的 IR 磨练成精致、紧凑的代码。
