# LLVM Pass: retdec-idioms

`retdec-idioms` 负责识别并优化编译器生成的特定指令序列（惯用法，Idioms），将其还原为语义更清晰、级别更高的逻辑表达。

## 核心功能

1.  **编译器模式匹配**：不同的编译器（如 GCC, MSVC, Borland）在处理相同的 C 代码时，会生成不同的汇编模式。该 Pass 通过预定义的模式库，将这些底层的“奇技淫巧”还原回真实的数学或逻辑运算。
2.  **指令简化**：将复杂的位操作、除法模拟等转换为标准的 LLVM 指令（如 `sdiv`, `rotl` 等）。
3.  **可读性提升**：消除编译器为了性能优化而引入的代码模糊性，使生成的伪代码更符合人类编写代码的习惯。

## 算法原理

### 1. 架构与编译器感知
- 从 `Config` 获取目标架构（x86, ARM, MIPS, PPC）和原始编译器信息。
- 根据编译器类型加载对应的分析集合（如 `IdiomsGCC`, `IdiomsVStudio`, `IdiomsBorland` 等）。

### 2. 习语交换（Idiom Exchange）
- 遍历函数内的所有基本块和指令。
- 对每条指令，依次运行对应的习语校验函数。常见模式包括：
    - **逻辑化简**：
        - `x & 0` -> `x = 0`
        - `x | -1` -> `x = -1`
        - `x ^ x` -> `x = 0`
    - **算术提升**：
        - 将基于倒数乘法（Reciprocal multiplication）和位移实现的“快速除法”还原为标准的 `sdiv` 或 `udiv` 指令。
        - 将位移和或运算组合（如 `(x << 8) | (x >> 24)`）还原为位循环操作（Rotate）。
    - **编译器特定技巧**：
        - 识别 Borland 或 MSVC 特有的、用于实现特定语言特性（如异常处理或位域访问）的指令序列。

### 3. 指令替换
- 当某个模式匹配成功时，Pass 会创建一个新的、语义等价的单条或少数几条指令。
- 使用新指令替换旧的指令序列。
- 递归清理掉因此变得多余的中间结果。

## 算法流程

1.  初始化：根据二进制元数据确定编译器和架构。
2.  函数遍历模式：
    - 对每个函数运行 `runOnFunction`。
    - 针对指令迭代器进行扫描。
    - 运行具体的子类分析器（如 `doAnalysis`）。
3.  执行具体匹配：调用编译器特定类中的 `exchange...` 系列函数进行尝试。
4.  更新 IR：执行原子级指令交换。

## 总结
`retdec-idioms` 是连接汇编级微观操作与 C 语言级宏观逻辑的重要桥梁。它通过逆向应用编译器的优化策略，将晦涩的优化指令还原为直观的编程意图，是生成可读反编译结果的关键 Pass 之一。
