# LLVM Standard Pass: constmerge (Merge Duplicate Global Constants)

`constmerge` 负责识别并合并内容完全相同的全局常量。

## 核心功能

1.  **常量去重**：如果模块中定义了多个具有相同数据内容（例如两个相同的字符串字面量）的只读全局变量，则将它们合并为同一个。
2.  **引用重定向**：将对所有重复常量的引用统一重定向到保留下来的那个常量上。

## 算法原理

- **内容指纹**：计算每个常量初始化器的哈希值或通过深度内容对比来判定一致性。

## 在 RetDec 中的作用
在反编译生成的代码中，许多地方可能重复引用相同的常量数组或掩码表。合并它们能使代码结构看起来更清晰，更符合人类减少重复定义的编码习惯。
