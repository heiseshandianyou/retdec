# LLVM Standard Pass: globalopt (Global Optimization)

`globalopt` 负责对全局变量、函数和全局别名进行系统级的转换和优化。

## 核心功能

1.  **全局变量标量化**：将包含单一元素的全局结构体或数组展开为独立的全局变量。
2.  **局部化**：如果一个全局变量仅被单个函数使用，尝试将其转换为该函数内的局部变量。
3.  **死全局变量删除**：移除所有从未被引用的全局变量、函数和别名。
4.  **只读变量常量化**：如果一个全局变量在初始化后从未被修改，将其转为 `constant` 以便于后续在各处进行常量折叠。

## 算法原理

- **引用分析**：扫描整个模块，建立全局符号的引用图。
- **多阶段处理**：首先评估全局初始化代码，然后针对性地修改符号属性，最后删除无用项。

## 在 RetDec 中的作用
二进制程序通常包含大量的全局数据段。`globalopt` 有助于识别出哪些数据区域实际上是常量字符串、配置表或仅供内部使用的私有数据，从而使反编译出的代码结构更加清晰，符合“模块化”编程的习惯。
