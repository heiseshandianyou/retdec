# retdec-select-fncs

`retdec-select-fncs` 是 RetDec 中的一个实用 Pass，用于根据用户的配置，仅保留特定代码范围或特定名称的函数体，而删除其他所有函数的实现。

## 功能概述

在进行大规模二进制反编译时，用户可能只对某些特定函数（如主逻辑函数、漏洞函数）感兴趣。如果反编译整个文件，不仅速度慢，而且结果中会充斥大量无关代码。`retdec-select-fncs` 允许用户通过配置文件指定“感兴趣”的范围，从而实现局部反编译，显著加快分析过程并让结果更加聚焦。

## 算法流程

该 Pass 的算法逻辑如下：

1.  **配置检查**：
    -   检查全局配置（Config）。如果用户没有在参数中指定任何选中的范围（`selectedRanges`）或选中的函数（`selectedFunctions`），则该 Pass 不执行任何操作。

2.  **函数遍历与过滤**：
    -   遍历 LLVM 模块中的所有函数定义。跳过只有声明没有定义的函数（Declarations）。

3.  **保留判定逻辑**：
    -   **按地址范围判定**：
        -   获取函数在二进制文件中的原始地址范围（Start to End）。
        -   检查该范围是否与用户在配置中指定的任何“选中范围”（Selected Ranges）有交集。
        -   如果函数起始地址落在选中范围内，或者选中范围覆盖了函数的一部分，则标记为“保留”。
    -   **按名称判定**：
        -   检查函数名称是否出现在用户指定的“选中函数”（Selected Functions）列表中。
        -   如果匹配成功，则标记为“保留”。

4.  **执行删除（`deleteBody`）**：
    -   如果一个函数既不在指定的地址范围内，也不是指定的函数名，则判定为“未被选择”。
    -   对于未被选择的函数，调用 `f.deleteBody()`。
    -   **注意**：`deleteBody` 只删除函数体，保留函数签名。这意味着该函数在 IR 中变为一个声明，原本对它的调用依然有效，但不再反编译其内部逻辑。

## 相关文件

-   `select_functions.cpp`: Pass 的主要实现逻辑。
-   `select_functions.h`: 类定义。

## 总结

`retdec-select-fncs` 是实现“按需反编译”的关键工具。它通过在反编译流程的早期裁剪掉不需要研究的函数内容，极大提高了分析大型固件或复杂二进制程序时的效率，也为后续更耗时的深度分析（如数据流和类型推断）减轻了负担。
