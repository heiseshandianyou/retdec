# LLVM Pass: retdec-class-hierarchy

`retdec-class-hierarchy` 负责重建 C++ 的类继承层次结构、虚函数表（Vtables）以及构造/析构函数信息。

## 核心功能

1.  **类结构还原**：通过分析二进制文件中的嵌入式元数据（RTTI），恢复类名及其父子继承关系。
2.  **虚表重建**：识别内存中的虚函数表，并将其项映射为对应的 LLVM 函数，生成结构化的全局变量。
3.  **构造/析构函数识别**：结合对目标地址的定值分析，寻找初始化或清除对象虚表指针的函数，并将其归类为构造或析构函数。
4.  **配置增强**：将还原出的面向对象模型注入 RetDec 配置，为最终生成高质量的 C++ 伪代码提供保障。

## 算法原理详解

### 1. RTTI 解析算法
针对不同编译器，`retdec-class-hierarchy` 采用了差异化的解析策略：

-   **Itanium ABI (GCC/Clang)**：
    -   解析 `vtable` 的 `-1` 偏移处获取 `type_info` 指针。
    -   根据 `type_info` 的类型进行分发：
        -   `abi::__si_class_type_info`：识别单继承，记录基类。
        -   `abi::__vmi_class_type_info`：识别多继承或虚继承，解析基类数组，记录每个基类的偏移量和属性（如 `is_virtual`）。
-   **MSVC ABI**：
    -   寻找虚表上方的 `RTTICompleteObjectLocator`。
    -   通过 `ClassHierarchyDescriptor` 访问 `BaseClassArray`。
    -   遍历基类描述符，提取类名以及该类在多重继承中的 `this` 指针偏移量（`where` 结构）。

### 2. 虚表与 IR 映射
-   **结构化表示**：为每个虚表创建一个 LLVM `StructType`，其成员类型根据虚表项所指向的函数签名确定。
-   **全局变量化**：在模块中生成对应的 `GlobalVariable`，并设置初始值为指向各成员函数的指针。
-   **解引用关联**：通过 `insn.addr` 元数据，将 IR 中的间接调用与具体的虚表项关联起来。

### 3. 构造/析构函数识别（核心启发式）
该算法基于 `ctor_dtor` 分析组件，通过双向扫描识别函数角色：

-   **候选筛选**：搜索所有包含“写入已知虚表地址”操作的函数作为候选。
-   **前向扫描 (Constructor 识别)**：
    -   识别模式：`[调用父类构造函数] -> [写入当前类虚表地址]`。
    -   如果函数在修改 `this` 指针指向当前虚表**之前**调用了其他候选函数，则判定为构造函数。
-   **后向扫描 (Destructor 识别)**：
    -   识别模式：`[写入当前类虚表地址] -> [调用父类析构函数]`。
    -   如果函数在修改 `this` 指针指向当前虚表**之后**调用了其他候选函数，则判定为析构函数。
-   **双向传播 (Propagation)**：
    -   对于无法仅凭扫描确定的函数（如不调用父类的基类构造），通过调用链进行推导。
    -   如果已知函数 A 是构造函数且它调用了函数 B，则 B 必定也是构造函数。

### 4. 偏移量追踪 (this 指针分析)
-   通过追踪对 `this` 指针的加减运算（`getOffset()` 递归分析），确定 vtable 存储在对象的哪个位置。
-   这对于还原多继承中非首位基类的 vtable 存储至关重要（偏移量通常不为 0）。

## 算法流程

1.  加载二进制镜像中的 RTTI 数据。
2.  **创建基础类信息**：遍历 RTTI，为每个识别出的类型在 `ClassHierarchy` 中创建 `Class` 对象。
3.  **建立继承链**：根据解析出的父类信息，连接 `Class` 对象的父类引用。
4.  **构建虚表全局变量**：根据 vtable 项的函数引用，在 LLVM 模块中生成结构化常量。
5.  **运行 ctor/dtor 识别逻辑**。
6.  **持久化输出**：将汇总后的类信息、虚函数成员及其访问属性写入反编译器的全局配置文件。

## 总结
该 Pass 是 RetDec 支持 C++ 逆向分析的核心。通过精准解析复杂的编译器底层对象模型，它将散乱的跳转地址转化为具有明确类归属和层次关系的面向对象结构，极大地提升了 C++ 程序反编译结果的可读性。
