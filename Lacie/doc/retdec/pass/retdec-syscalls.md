# retdec-syscalls

`retdec-syscalls` 是 RetDec 中的一个 LLVM Pass，用于识别并修复（转换）二进制代码中的系统调用（Syscalls）。

## 功能概述

在逆向工程中，系统调用通常以特定的汇编指令（如 x86 的 `int 0x80` 或 ARM 的 `svc`）形式出现。这个 Pass 的目的是将这些低级的系统调用指令转换为更易读的 LLVM `call` 指令，指向具体的系统调用函数（如 `read`, `write`, `open` 等）。

## 算法流程

该 Pass 的核心算法可以分为以下几个步骤：

1.  **架构识别**：
    根据配置信息（`Config`）识别目标程序的架构（MIPS, ARM, ARM64, x86 等）。

2.  **指令扫描**：
    遍历模块中的所有函数 and 指令，寻找特定架构下的系统调用特征指令。
    -   **x86 (Linux 32-bit)**：寻找 `int 0x80` 指令。
    -   **ARM**：寻找 `svc` 指令。
    -   **MIPS**：寻找 `syscall` 指令。

3.  **提取系统调用号**：
    在发现系统调用指令后，算法会回溯查找设置系统调用号的指令。
    -   例如在 x86 中，系统调用号通常存储在 `eax` 寄存器中。Pass 会查找最近一次对 `eax` 寄存器的 `StoreInst`。
    -   如果能确定系统调用号是一个常量，则继续下一步。

4.  **查找对应函数**：
    -   使用内部预定义的系统调用表（`std::map<uint64_t, std::string>`），将系统调用号映射为函数名称。
    -   在 LLVM 模块或 LTI（Library Type Information）提供者中查找该名称对应的 `Function` 对象。

5.  **指令转换（Transformation）**：
    如果找到了对应的函数，Pass 会执行以下转换：
    -   **参数获取**：根据 ABI（应用二进制接口）定义，从对应的系统调用参数寄存器中获取参数值（使用 `LoadInst`）。
    -   **创建调用**：在系统调用指令的位置创建一个 `CallInst`，调用识别出的系统调用函数，并传入获取的参数。
    -   **处理返回值**：如果函数有返回值，根据 ABI 将 `CallInst` 的结果存储回系统调用返回值寄存器。
    -   **标记系统调用**：在配置中将该函数标记为 `isSyscall`，以便后续 Pass 处理。

## 相关文件

-   `syscalls.cpp`: Pass 的主要入口和通用转换逻辑。
-   `x86.cpp`, `arm.cpp`, `arm64.cpp`, `mips.cpp`: 各架构特定的系统调用识别实现和映射表。
-   `syscalls.h`: Pass 的类定义。

## 总结

`retdec-syscalls` 通过将硬件相关的陷阱指令转换为语义明确的函数调用，极大地提高了反编译代码的可读性，并为后续的类型推断和数据流分析奠定了基础。
