# retdec-types-propagation

`retdec-types-propagation` 是 RetDec 中的一个数据类型传播 Pass，它通过分析指令之间的数据依赖关系，将已知的类型信息在 LLVM 模块内的值、指令和函数之间进行传播。

## 功能概述

虽然 `retdec-simple-types` 已经完成了一轮核心的类型恢复，但在反编译的某些阶段，仍需要更精细、更具全局性的类型流转。`retdec-types-propagation` 的目标是在已有的类型分析基础上，利用更广泛的数据流线索（特别是跨函数调用的关系），进一步填补类型信息中的空白，确保整个程序在类型语义上的一致性。

## 算法流程

该 Pass 的算法也是基于等价类（Equivalence Sets）的概念，但其侧重点在于“传播”：

1.  **构建等价集（buildEquationSets）**：
    -   遍历模块中的所有函数、参数和指令。
    -   对于每个“根”值（Root Value），如果它尚未被处理，则启动一个新的等价集搜索（`processRoot`）。

2.  **符号化遍历与收集（processValue / processUserInstruction）**：
    -   使用队列（Queue）和广度优先搜索（BFS）来收集所有相互关联的值。
    -   **传播规则**：
        -   **算术/逻辑运算**：加、减、乘、除、与、或、异或等指令的所有操作数（Operands）以及结果指令本身都被视为类型关联。
        -   **类型转换**：`Trunc`, `ZExt`, `SExt` 等指令会将其输入和输出关联。
        -   **返回指令**：`ReturnInst` 会将其返回的值、该返回指令本身以及所属的 `Function` 对象关联起来。
        -   **函数调用**：`CallInst` 会将实参（Arguments）与其调用的 `Function` 对象的形参一一对应关联。

3.  **结果输出（现有版本特点）**：
    -   当前的实现（基于源码快照）主要集中在通过 RDA（到达定值分析）和 BFS 遍历构建出这些等价集。
    -   它会遍历这些集合，并将识别出的关联关系（例如哪个函数参数与哪些指令、哪些返回值在同一个类型流中）记录并准备应用。

## 相关文件

-   `types_propagator.cpp`: 核心逻辑，包含 BFS 搜索和指令关联规则。
-   `types_propagator.h`: 类定义。

## 总结

`retdec-types-propagation` 是 RetDec 类型恢复体系中的“连通者”。它不一定产生全新的类型（虽然它也参与推断），但它确保了“同一个值”在流经不同指令、甚至被传递进出函数时，其类型身份能够被正确地追踪和同步。这对于最后生成类型定义严谨的 C 代码（例如避免不必要的指针到整数转换）具有重要意义。
