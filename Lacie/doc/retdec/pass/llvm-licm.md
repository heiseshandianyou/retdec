# LLVM Standard Pass: licm (Loop Invariant Code Motion)

`licm` 是循环优化中最著名的技术之一，负责将“循环无关代码”移出循环体。

## 核心功能

1.  **代码外提（Hoisting）**：将计算结果在每次迭代中都保持不变的指令移动到循环的 Preheader 中。
2.  **存储下沉（Sinking）**：将循环内对内存的写操作，如果最后其结果是固定的，移动到循环的退出块中。
3.  **标量提升（Promotion）**：如果循环内频繁读写同一个内存地址，将其提升为寄存器（加载到寄存器后在循环内操作，循环结束后存回）。

## 算法原理

- **恒定性判定**：指令的所有操作数要么是常量，要么是在循环外定义的。
- **安全性检查**：外提指令不能有副作用（或其副作用在 Preheader 中是安全的），且必须保证即使循环一次也不执行，外提的操作也不会导致致命错误。

## 在 RetDec 中的作用
反编译生成的原始指令链中往往包含大量冗余的内存计算和重复的地址加载。`licm` 能帮助有效剥离循环体中的杂音，让开发者一眼看出循环的核心计算逻辑。
