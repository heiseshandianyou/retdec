# LLVM Standard Pass: sccp (Sparse Conditional Constant Propagation)

`sccp` 是一种结合了常量分析和基本块可达性分析的高级传播技术。

## 核心功能

1.  **常量传播**：将已知的常量值沿着 SSA 链向后传播到所有使用点。
2.  **基于条件的传播**：通过解析条件跳转（如 `br i1 true, ...`），它可以识别出某些路径是永远不会被执行的，从而忽略这些路径带来的值合并，获得比普通常量传播更精确的结果。
3.  **格理论建模（Lattice Theory）**：将每个值建模为一个格（Undef -> Constant -> Overdefined），并迭代计算固定点。

## 算法原理

- **工作队列算法**：维护两个队列，一个用于指令，一个用于基本块。
- **迭代更新**：当一个基本块被证明可达时，分析其指令。当一条指令产生新常量时，将其所有使用者加入队列。通过这种“稀疏”迭代，高效地求得整个函数的常量分布情况。

## 在 RetDec 中的作用
反编译中充满了通过地址计算得出的常量指针或分支条件。`sccp` 能够帮助 RetDec 有效地剥离这些看似动态实则静态的执行路径，大大简化了生成的代码。
