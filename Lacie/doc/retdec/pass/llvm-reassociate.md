# LLVM Standard Pass: reassociate (Reassociate Expressions)

`reassociate` 负责重排交换律和结合律表达式（如加法、乘法、位操作）的操作数顺序，以暴露更多的优化机会（如常量折叠）。

## 核心功能

1.  **表达式重排**：将 `(a + 2) + b` 转换为 `(a + b) + 2`，从而使常量更容易与后续的其他常量结合。
2.  **因子分解**：类似于 `(a * 5) + (a * 3) -> a * 8`。
3.  **计算代价优化**：调整操作数顺序以减少算术强度。

## 算法原理

- **规范化权重**：为每种操作数分配权重（如常量权重最低），并将表达式树重构为由低权重到高权重排列的形式。
- **线性排序**：将复杂的表达式展平，应用加法/乘法的一致性规则。

## 在 RetDec 中的作用
解码器生成的地址计算逻辑往往充满杂乱的偏移加法。`reassociate` 通过标准化这些算术链，极大地方便了后续的 `instcombine` 识别出底层的数组访问模式。
