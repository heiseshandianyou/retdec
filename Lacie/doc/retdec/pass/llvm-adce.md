# LLVM Standard Pass: adce (Aggressive Dead Code Elimination)

`adce` 是一种激进的死代码消除算法，它默认所有指令都是死的，除非能证明其由于某种原因必须存在。

## 核心功能

1.  **反向标记存活**：从所有具有副作用的指令（如存储、函数调用、返回）出发，沿着数据依赖和控制依赖反向遍历，标记所有必须存活的指令。
2.  **死指令物理移除**：所有未被标记存活的指令均被视为垃圾并被物理删除。
3.  **死分支清理**：如果一个条件跳转的两个分支都不包含任何存活代码，且该跳转不影响存活指令的执行频率，则将其简化。

## 算法原理

- **控制依赖图（CDG）**：与普通常量消除不同，ADCE 需要分析控制流依赖，以确保即使不直接产生数据的指令，如果它决定了其他重要指令的执行，也能被保留。

## 在 RetDec 中的作用
在 RetDec 这一系列重型转换（如从机器码到 IR 再到各种抽象提升）之后，IR 中会残留大量支离破碎的逻辑。`adce` 是最终的“大扫除”，确保只有真正有意义的逻辑留在反编译结果中。
